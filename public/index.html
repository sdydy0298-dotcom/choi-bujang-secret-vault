내 자료실

메모 자료 요청은 Vercel 서버 함수에 모으고 원본 저장소의 직접 접근 권한은 차단합니다.

로그인은 Supabase Auth를 유지하고, 메모 읽기·추가·수정·삭제는 서버 함수만 호출합니다.

로그인됨

기기 승인미등록

앱을 설치하거나 로그인해도 이 기기는 자동 승인되지 않습니다. 운영자가 승인한 기기만 서명된 요청으로 자료를 볼 수 있습니다.

승인 전에는 보호 자료를 표시하지 않습니다.

기기 개인키와 로그인 토큰은 브라우저 영구 저장소에 넣지 않고 현재 페이지 메모리에서만 사용합니다. 새로고침하거나 창을 닫으면 다시 승인 요청이 필요합니다. 오프라인에서는 자료를 열 수 없습니다.
